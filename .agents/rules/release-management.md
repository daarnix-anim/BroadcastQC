# Release and Versioning Workflow

1. **Do NOT automatically create new releases on every bugfix/tweak.**
2. **Before pushing, creating a Git Tag, or deploying a GitHub Release:**
   - ALWAYS explicitly ask the user what version number they want to use.
   - ALWAYS show the current/previous version number (e.g. `Текущая версия: v0.9.1. Какую версию назначить для релиза? (например, v0.9.1.2 или v0.9.2)`).
3. **If updating an existing release**, update the assets / tag without spawning unwanted version numbers.
