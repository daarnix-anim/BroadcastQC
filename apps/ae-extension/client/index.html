Broadcast QC Extension
v0.8.3
Интеллектуальный контроль качества для motion-design проектов и ТВ-вещания.
• Поддерживаемый хост: Adobe After Effects 2026.2+
• Архитектура: CEP 11-13 (HTML5 + Node.js + ExtendScript)
• Оффлайн спеллчекер (RU/EN) + 1-Click Auto-Fix в слоях AE
• Smart Stable State геометрия (EBU R95 / SMPTE)
• Контроль скорости чтения (WPM / CPS) и аудит Guide-слоев
• Интеграция с локальными LLM (Ollama, LM Studio) и API
• Экспорт паспорта качества в HTML / PDF
